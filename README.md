## ✦ About the Project

SeaPulse is an AIS-based maritime surveillance platform designed to monitor vessel movements, identify unusual behaviour, and detect potential maritime risks in real time.

It transforms vessel tracking data into meaningful insights through interactive visualizations and risk detection mechanisms.

## ✦ Key Features

- Real-time AIS vessel monitoring
- Geofence violation detection
- Loitering and route deviation alerts
- AIS signal silence detection
- GPS anomaly detection
- Interactive maritime dashboard
